# Chery-Pinetown-Lead

Technologies : HTML, CSS, JavaScript, Firebase

Developed a web-based lead management system for registering and tracking customer referrals for vehicles sales.
Implemented unique lead IDs, customer information, vehicle/model selection, referral tracking, lead status updates and commission records.
Designed a dashboard to help monitor leads from registration through qualification, qoutation, sale and commission payout.
Applied database-driven development using Firebase for storing and managing lead information
